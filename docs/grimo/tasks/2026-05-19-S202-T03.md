# S202-T03: Fixture manifest, DB guard, setup and teardown projects

## 對應規格
S202：Production E2E Fixture Runner

## 這個 task 要做什麼
這個 task 完成後，Playwright 會先跑 `setup fixtures` project，產出 `e2e/results/fixtures.json`，最後跑 `teardown fixtures` project 清掉 Compose stack。fixture runner 執行任何 `TRUNCATE` / `DELETE` / projection SQL 前，都會檢查 DB name、host、active profile，避免清錯資料庫。

## 使用者情境（BDD）
Given（前提）T02 的 Compose app 已啟動，DB 是 `skillshub_e2e`
When（動作）執行 `cd e2e && npx playwright test --project "setup fixtures"`
Then（結果）`e2e/results/fixtures.json` 存在，內容包含 `runId`、`baseUrl`、`profiles.empty`
And（而且）setup 第一段打 `POST /internal/test/reset`，若收到 2xx / 3xx 就 fail 並印出 `production app exposes forbidden test route`
When（動作）fixture runner 收到 DB name `skillshub`
Then（結果）runner 在 destructive SQL 前 fail，錯誤訊息包含 `Refusing to reset non-e2e database`
And（而且）teardown 執行 `docker compose -f compose.e2e.yaml down -v --remove-orphans`

## 先做 POC
- POC：required — DB guard 和 setup/teardown 是會刪資料的路徑，必須先用 isolated values 驗錯誤分支。
- Fixture：
  - `positive-fixture`: `{ host: "localhost", database: "skillshub_e2e", activeProfiles: "local" }` → guard 通過
  - `negative-fixture`: `{ host: "prod-db", database: "skillshub", activeProfiles: "prod" }` → throw `Refusing to reset non-e2e database`
- POC 跑完必須印出 `S202 T03 POC PASS`。

## 正式程式怎麼做
- 新增 `e2e/fixtures/db-guard.ts`
  - export `assertE2eDatabase(...)`
  - database 必須完全等於 `skillshub_e2e`
  - host 只允許 `localhost`、`127.0.0.1`、`db`
  - active profile 必須完全等於 `local`
- 新增 `e2e/fixtures/manifest.ts`
  - export `FixtureManifest` / `FixtureSkill`
  - export `readManifest()` / `writeManifest()`
- 新增 `e2e/fixtures/setup.fixtures.ts`
  - best-effort cleanup prior stack
  - forbidden route check
  - wait pending `event_publication` 歸零
  - guarded reset allowlist tables
  - write initial manifest
- 新增 `e2e/fixtures/teardown.fixtures.ts`
  - remove transient manifest if needed
  - run `docker compose -f compose.e2e.yaml down -v --remove-orphans`
- 更新 `e2e/playwright.config.ts`
  - 新增 `setup fixtures` project
  - 新增 `teardown fixtures` project
  - `chromium` depends on `setup fixtures`
