# S202-T06: Mock OAuth browser login storage state

## 對應規格
S202：Production E2E Fixture Runner

## 這個 task 要做什麼
這個 task 完成後，Playwright 可以用 mock OAuth 跑現有 Google 登入同一條 browser flow，並把 developer/viewer/admin session cookie 存成 `e2e/playwright/.auth/*.json`。匿名打 `/` 時 header 看到「登入」；developer storageState 打 `/` 時 header 看到「開啟使用者選單」，`GET /api/v1/me` 會回 mock config 中的 email/name/picture。

## 使用者情境（BDD）
Given（前提）`e2e/compose.e2e.yaml` 啟動 mock OAuth server，且 app env 有 `SKILLSHUB_SECURITY_OAUTH_LOGIN_ENABLED=true`
When（動作）執行 `cd e2e && npx playwright test --project "setup auth"`
Then（結果）`e2e/playwright/.auth/developer.json` 和 `e2e/playwright/.auth/viewer.json` 存在
And（而且）setup auth 用 browser flow 取得 session cookie，不手寫 cookie 檔
And（而且）developer session 打 `/api/v1/me` 回 `developer@example.test`、developer name、picture URL
And（而且）issuer / token exchange URI 不一致時，setup auth fail 並印出 `mock OAuth login issuer mismatch`

## 先做 POC
- POC：required — browser 在 host、app 在 Docker container，mock OAuth issuer/endpoint host 容易不一致。
- Fixture：
  - `positive-fixture`: `/oauth2/authorization/skillshub?returnTo=/` → callback → `/api/v1/me` 回 developer email/name/picture
  - `negative-fixture`: issuer mismatch 或 token endpoint unreachable → fail with `mock OAuth login issuer mismatch`
- POC 跑完必須印出 `S202 T06 POC PASS`。

## 正式程式怎麼做
- 修改 `backend/config/oauth-mock-config.json`
  - `admin-client` / `developer-client` / `viewer-client` claims 補：
    - `email`
    - `name`
    - `picture`
- 修改 `e2e/compose.e2e.yaml`
  - app 開 `SKILLSHUB_SECURITY_OAUTH_LOGIN_ENABLED=true`
  - 宣告 `spring.security.oauth2.client.registration.skillshub.*`
  - 若要 viewer/admin browser sessions，新增 registrations `skillshubviewer` / `skillshubadmin`
  - 若 single issuer URI 無法同時滿足 host browser 與 app container，改用 explicit `authorization-uri` / `token-uri` / `jwk-set-uri`
- 新增 `e2e/fixtures/auth.setup.ts`
  - 匿名 context 驗 header「登入」
  - developer login flow 後存 `playwright/.auth/developer.json`
  - viewer/admin login flow 後存對應 storageState
  - 每個 storageState 存完後打 `/api/v1/me` 驗 expected claims
- 更新 `e2e/tests/_fixtures.ts`
  - export `AUTH_STATES`
  - export `authState(role)`
- 確認 `e2e/.gitignore` 已包含 `playwright/.auth/`
